# Photography Portfolio

在线访问
- GitHub Pages: https://stevec-otaku.github.io/Photography-Portfolio/

说明
- 技术栈：Next.js 14（App Router）+ TypeScript + Tailwind CSS
- 构建：`npm run build`（静态导出到 `out/`）
- 部署：GitHub Actions 自动发布到 Pages（Source 选择 GitHub Actions）

路径前缀
- 站点为项目页，路径前缀为 `/Photography-Portfolio`；静态资源与图片已适配
